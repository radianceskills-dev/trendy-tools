Make a better flowchart prompt

Name the audience, the start and end states, the person responsible for each step, and the conditions for every decision. State what happens when information is missing or a request is rejected. Ask for a simple first draft before adding exception paths.

Review before using

  • Every decision has labeled outcomes.
  • Rejected or failed cases have a clear next step.
  • Loops have an exit condition.
  • Step names describe actions rather than vague stages.
